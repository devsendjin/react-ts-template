# React + TypeScript + Vite template

A minimal starter with an opinionated folder structure: path-aliased `components` (`App`, `entities`, `ui`), `hooks`, `context`, `services`, and `utils`, plus Sass (CSS Modules) styling and a small `dayjs`-based date/time utility.

## Getting started

```bash
pnpm install
pnpm dev
```

Other scripts: `pnpm build`, `pnpm preview`, `pnpm lint:tsc`, `pnpm format`.
